# Diagrammes d'architecture

Ces diagrammes SVG sont dérivés du code source du dépôt.

- [Architecture des projets](architecture-projets.svg) : dépendances de compilation et principaux systèmes externes.
- [Classes du moteur d'exécution](classes-moteur-execution.svg) : services, interfaces et types de pas de workflow centraux.
- [Séquence d'une tâche planifiée](sequence-tache-planifiee.svg) : chargement, exécution séquentielle, rapport et replanification.

Les diagrammes décrivent l'architecture observée au 12 août 2026 pour la version 1.4.1. Ils sont
conservés comme photographie historique et ne représentent pas les extensions ultérieures de
routage ou de répétition `forEach`. Le moteur actuel est décrit dans
[`../Technical-Manual.html`](../Technical-Manual.html) et [`../ARCHITECTURE-LEDGER.md`](../ARCHITECTURE-LEDGER.md).
